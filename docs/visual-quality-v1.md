# 달빛 윷마당 · 시각화 품질 기준 v1.0

대상: GitHub `zaruous/dalbit-yut`, React + TypeScript, 2026-10-26 개선판.

## 품질 평가 기준 (100점)

| 항목 | 배점 | 합격 조건 |
|---|---:|---|
| 배경 및 분위기 | 20 | 독립 한옥/산/노을/마루 레이어, UI 잔상 없음, 텍스트를 방해하지 않는 적절한 대비 |
| 플레이어 | 15 | 아바타, 4말, 현재 차례, 진행 상황을 한눈에 구별, 시각 상태와 실제 게임 상태 일치 |
| 윷 던지기 | 20 | 네 가락 개별 회전/착지, 이펙트와 결과 동기화, 낙이 실제 멍석 밖에 표현됨 |
| 말 이동 | 20 | 사용자가 말을 클릭하고 목적지를 확정, 이동 번호/경로/점프/착지·잡기 연출 |
| 윷판 가독성 | 10 | A/B 맵 칸·갈림길·경로·도착 지점 명확, 선택 가능한 목적지가 뚜렷함 |
| 화면 구성 | 10 | PC 한 화면에 판+던지기+버튼, 모바일에서 두 영역 연속 배치, 오버랩 없음 |
| 반응형·성능 | 5 | 1600×900/1366×768/390×844/360×800, 모바일 터치, reduced motion 지원 |

합격: 합산 **85/100점 이상**, 그리고 배경·플레이어·윷 던지기·말 이동은 각각 5점 만점에 4점 이상. 예외, 결과·이펙트 불일치, 모바일 가로 넘침, 수동 말 이동 실패는 점수와 무관하게 불합격.

**점수는 사람의 시각 검수가 필요한 주관 평가이므로 자동 테스트 결과만으로 85점 합격이라고 표기하지 않습니다.**

## 이번 개선 내용

- 배경에 기존 합성 UI가 남아 있던 문제를 제거하고 `hanok-autumn-scene.svg`로 교체
- 카드 아바타·말 상태·현재 차례 가독성 및 진행 상태바 강화
- 멍석의 짜임/외곽 경계, 금빛 파티클, 붉은 버튼, 개별 윷가락의 회전 애니메이션 정리
- 선택 말의 캡션, 경로별 번호, 목적지 터치 영역, 이동 착지 충격파 추가
- 노트북에서 사용하지 않는 이동 가이드를 축소해 판·던지기·버튼을 한 화면에 배치
- 모바일에서 윷판 다음에 던지기 영역이 오도록 유지, 배경 독립, 가로 넘침 방지

## 윷판 벡터 디테일 개선 (2026-10-27)

- 원목 결, 황동 상감, 네 귀퉁이 장석과 한지 섬유를 SVG 패턴·그라디언트로 표현했다. 확대용 래스터 이미지는 추가하지 않았다.
- 이동 칸에 금속 테두리와 곡면 음영을 추가하고, 갈림길·중앙·출발 칸의 색 구분을 유지했다. 이동 선의 밝은 상감과 말 표면의 반사광도 정리했다.
- 정적 판·칸에 적용됐던 CSS 필터를 제거하고 벡터 도형으로 음영을 표현했다. 이번 변경 후 FPS는 별도로 재측정하지 않았다.
- 타입 검사, 기본 150판/16225 assertions, AI 24판/2244 assertions, Vite 프로덕션 빌드 및 standalone preview 생성 통과.
- 실제 Chrome에서 두 맵 전환, 이중 링 맵의 결과 선택 → 대기 말 선택 → 황금 목적지 직접 클릭 → 이동·차례 종료를 확인했다. 소형 모바일 폭에서 가로 넘침이 없고 윷판 바로 아래 멍석·던지기 버튼이 이어짐을 확인했다.
- Windows에서 preview 빌드가 TypeScript의 셸 shim을 직접 실행하다 실패하던 문제는 Node로 TypeScript JS 진입점을 실행하도록 수정했다.
- 사람의 디자인 점수 및 실제 모바일 기기 성능은 이 검사에 포함하지 않았다.

## 기본 사각형 판·AI 관전 추가 (2026-10-27)

- 기본 사각형(S)이 첫 화면 및 AI 관전 바로가기의 기본판이다. 기존 A/B 맵 선택지는 유지한다. 상세는 [기본판과 관전 안내](./standard-board.md).
- 세 맵 일반 경기 225판, 탐색 AI 경기 36판, 기본판 경로·빽도·잡기·업기·완주 검사를 통과했다. Laya 연결 테스트 9개와 Vite 프로덕션 빌드·독립 미리보기 생성도 통과했다.
- Chrome에서 기본판 29개 자리와 사각형/X자 표시, 기본판 AI 4인의 자동 진행을 확인했다. 관전 정지 중 차례·말 위치·로그가 유지되고 재개 후 같은 경기에서 진행되는 것도 별도 탭에서 확인했다.
- 작은 모바일 폭의 관전 배치는 B 맵에서 가로 넘침 없이 확인했다. 실제 모바일 기기 성능·디자인 평점은 별도 검증 대상이다.
