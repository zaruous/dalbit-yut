# 달빛 윷마당 · 시각화 품질 기준 v1.0

대상: GitHub `zaruous/dalbit-yut`, React + TypeScript, 2026-10-26 개선판.

## 품질 평가 기준 (100점)

| 항목 | 배점 | 합격 조건 |
|---|---:|---|
| 배경 및 분위기 | 20 | 독립 한옥/산/노을/마루 레이어, UI 잔상 없음, 텍스트를 방해하지 않는 적절한 대비 |
| 플레이어 | 15 | 아바타, 4말, 현재 차례, 진행 상황을 한눈에 구별, 시각 상태와 실제 게임 상태 일치 |
| 윷 던지기 | 20 | 네 가락 개별 회전/착지, 이펙트와 결과 동기화, 낙이 실제 멍석 밖에 표현됨 |
| 말 이동 | 20 | 사용자가 말을 클릭하고 목적지를 확정, 이동 번호/경로/점프/착지·잡기 연출 |
| 윷판 가독성 | 10 | A/B 맵 칸·갈림길·경로·도착 지점 명확, 선택 가능한 목적지가 뚜렷함 |
| 화면 구성 | 10 | PC 한 화면에 판+던지기+버튼, 모바일에서 두 영역 연속 배치, 오버랩 없음 |
| 반응형·성능 | 5 | 1600×900/1366×768/390×844/360×800, 모바일 터치, reduced motion 지원 |

합격: 합산 **85/100점 이상**, 그리고 배경·플레이어·윷 던지기·말 이동은 각각 5점 만점에 4점 이상. 예외, 결과·이펙트 불일치, 모바일 가로 넘침, 수동 말 이동 실패는 점수와 무관하게 불합격.

**점수는 사람의 시각 검수가 필요한 주관 평가이므로 자동 테스트 결과만으로 85점 합격이라고 표기하지 않습니다.**

## 이번 개선 내용

- 배경에 기존 합성 UI가 남아 있던 문제를 제거하고 `hanok-autumn-scene.svg`로 교체
- 카드 아바타·말 상태·현재 차례 가독성 및 진행 상태바 강화
- 멍석의 짜임/외곽 경계, 금빛 파티클, 붉은 버튼, 개별 윷가락의 회전 애니메이션 정리
- 선택 말의 캡션, 경로별 번호, 목적지 터치 영역, 이동 착지 충격파 추가
- 노트북에서 사용하지 않는 이동 가이드를 축소해 판·던지기·버튼을 한 화면에 배치
- 모바일에서 윷판 다음에 던지기 영역이 오도록 유지, 배경 독립, 가로 넘침 방지

## 확인한 자동·실행 테스트

| 검사 | 결과 |
|---|---|
| `tsc -p tsconfig.json --noEmit` | 통과 |
| `npm test` | 통과: 팔각형·이중 링형 2~4인 150판 종료 |
| Chromium 1600×900 / 1366×768 | 가로 넘침 없음, 판·멍석·던지기 버튼 동시 표시 |
| Chromium 390×844 / 360×800 | 가로 넘침 없음, 보드 아래 던지기 연속 배치 |
| 유효 던지기 | 정상 결과 표시·차례 진행 |
| 대기 말 선택 → 황금색 목적지 클릭 | 통과, 말을 칸별로 이동 |
| 이중 링 맵 전환·강제 낙 | 통과, 윷가락 한 개가 밖에 표시되고 차례 전환 |
| 브라우저 JavaScript 런타임 오류 | 없음 |
| Vite production build | 미확인: npm 패키지 설치 네트워크 제한 |
| 실기기 FPS (PC 60 / 모바일 30 목표) | 미측정 |
| WCAG 텍스트/버튼 대비 상세 자동 측정 | 미측정 |
