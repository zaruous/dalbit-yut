# AI 전략과 검증

AI 대전은 `src-ts/aiEngine.ts`의 `chooseAIAction`을 사용합니다. 외부 API나 학습 모델 없이 브라우저 안에서 실행합니다.

- 맵의 갈림길을 고려한 남은 완주 거리를 평가합니다.
- 완주·잡기·추가 던지기·업기의 이득을 비교합니다.
- 상대가 다음 던지기로 잡을 수 있는 위치를 16가지 윷 면 조합의 확률로 평가합니다. 업힌 말은 함께 잡히는 손실도 반영합니다.
- 이미 보유한 결과를 최대 세 번의 이동까지 탐색해 결과 사용 순서와 경로를 고릅니다. 최초 후보 8개와 이후 단계별 후보 3개로 탐색을 제한합니다.
- 상대를 잡아 새 윷을 던져야 하거나 차례가 끝나면 탐색을 멈춥니다. 미래의 실제 난수나 윷 결과를 조회하지 않습니다.
- 같은 상태에서는 같은 선택을 합니다. 사람 플레이어는 기존처럼 결과·말·목적지를 직접 선택합니다.

## 재현

```bash
npm test
npm run build
node scripts/benchmark-ai.cjs 100 50
```

`npm test`는 기존 150판 시뮬레이션 외에 전술 테스트와 새 AI의 2~4인 게임 24판을 실행합니다. 전술 테스트는 완주, 승리, 잡기, 위험 회피, 도 다음 빽도, 중앙 정차를 위한 결과 순서, 합법적 이동, 입력 상태 보존, 난수 미사용을 확인합니다.

비교 프로그램의 인자는 맵·좌석별 시드 개수와 시드 오프셋입니다. 위 명령은 조정에 사용한 시드 1~50을 제외한 시드 51~150에서 두 맵과 두 좌석을 조합해 400판을 실행합니다. 상대는 기존 `gameEngine.scoreOption`을 사용한 AI입니다. 원래의 정렬 비교 중 무작위 점수도 재현합니다. 주사위 대신 사용하는 윷 난수와 기존 AI의 판단 난수는 별도 스트림이며, 같은 시드의 좌석 교대 대전에는 같은 좌석별 윷 스트림을 제공합니다. 양쪽 모두 낙 없이 동일한 윷 확률로 플레이합니다.

2026-10-26 검증 결과:

| 맵 | 개선 AI 승리 | 대전 수 | 승률 |
| --- | ---: | ---: | ---: |
| A | 118 | 200 | 59% |
| B | 131 | 200 | 65.5% |
| 합계 | 249 | 400 | 62.25% |

해당 실행의 9,887회 판단에서 평균 0.65ms, 95백분위 2.44ms, 최대 145.34ms였습니다. 실행 장비·초기 컴파일·부하에 따라 시간은 달라집니다. 이 승률은 위 2인 대전 표본의 결과이며 모든 상황에서의 승률을 보장하지 않습니다. 3~4인 게임은 정상 종료와 합법적 이동을 검증했으며 기존 AI 대비 승률은 측정하지 않았습니다.

평가는 상대의 다음 한 번 던지기 위협과 보유 결과 최대 세 번을 살펴보는 휴리스틱입니다. 상대의 여러 차례 대응이나 아직 나오지 않은 추가 던지기 전체를 탐색하지 않습니다.
