# AI 연속 던지기 검증 — 2026-10-27

검증 범위에서 **근거 없는 추가 던지기·차례 순서 오류·AI 동작 중복 예약은 재현되지 않았다.** 연속 던지기 자체는 관찰됐으며, 윷·모 또는 잡기로 얻은 추가 던지기로 설명됐다. 게임 로직은 수정하지 않았다.

## 실행 범위

모든 좌석을 현재 탐색 AI로 제어했다. Laya 실험 모델을 사용한 대전이 아니다.

| 검사 | 구성 | 실행량 | 위반 |
|---|---|---:|---:|
| 엔진 대전 | A/B × AI 2·3·4인 × 각 50개 별도 시드 | 300판, 26,475회 던짐, 25,889회 이동 | 0 |
| 실제 React 제어 코드 | A/B × AI 2·3·4인, 각 1판 | 6판, 706회 던짐, 692회 이동 | 0 |
| 정상 속도 화면 표본 | B, AI 4인, 원래 타이머·CSS 애니메이션 | 20회 던짐, 19회 이동 | 0 |

두 번째 검사는 실제 마운트된 App의 `checkAI`, `componentDidUpdate`, `throwYut`, `commitMove`, `moveTick`을 그대로 실행했다. 대기 시간의 상대 순서는 유지하는 가상 타이머로 가속하고 CSS 애니메이션을 껐다. 세 번째 검사는 원래 타이머와 애니메이션으로 실행했으며 20회 던지기에서 의도적으로 중단한 부분 표본이다.

## 독립적인 던지기 권한 검사

각 차례 시작 때 던지기 권한을 1개 지급하고 실제 던질 때 1개 차감했다. 유효 윷·모나 상대 잡기가 일어날 때만 1개를 추가 지급했다. 업기·일반 이동·단순 말 완주는 권한을 지급하지 않았다. 여러 말을 한 번에 잡아도 추가 권한은 1개다.

엔진 300판의 전체 회계는 다음과 같이 정확히 일치했다.

| 던지기 권한 출처 | 횟수 |
|---|---:|
| 차례 시작 | 16,530 |
| 윷 | 1,633 |
| 모 | 1,695 |
| 잡기 | 6,617 |
| 합계 | **26,475** |
| 실제 던지기 | **26,475** |

실제 React 가속 검사도 차례 시작 422 + 추가 권한 284 = 실제 던지기 706으로 일치했다. 정상 속도 표본도 차례 시작 10 + 잡기 10 = 실제 던지기 20으로 일치했다.

추가로 다음을 검사했다.

- 권한 없는 던지기, 진행 중인 동작이 끝나기 전 두 번째 AI 동작 예약
- 일반 결과/잡기 없는 이동 뒤 잘못된 추가 던지기
- 다음 플레이어로의 순환 순서와 차례 번호, 이전 플레이어 결과의 잘못된 승계
- 실제 윷 앞면 개수와 결과 값 일치, 이동·던지기 횟수 중복 증가
- 잡기 판정과 실제 목적지의 상대 말 수 일치, 완주한 말 네 개를 가진 승자

## 사용자가 연속 턴처럼 느낄 수 있는 실제 사례

### 이동 전 5번 연속 던지기

A 맵, AI 2인, 시드 41의 36번째 차례:

`모 → 윷 → 윷 → 모 → 개 → 말 이동`

앞의 네 결과가 각각 추가 던지기를 줬다. 마지막 개는 추가 던지기를 주지 않고 이동 단계로 전환했다.

### 한 차례에 9번 던지기

B 맵, AI 3인, 시드 38의 16번째 차례에서는 윷·모와 잡기 보너스가 이어져 한 차례에 9번 던졌다. 중간에 말 이동과 잡기가 있으므로 9번을 이동 없이 연속으로 던진 것은 아니다. 상세 경로는 JSON의 `engine.longestTurn.events`에 있다.

### 윷·모 없이 4번 던지기 — 정상 속도 관찰

B 맵, AI 4인, 시드 910104의 6번째 차례:

`도 → 이동·잡기 → 걸 → 이동·잡기 → 개 → 이동·잡기 → 걸 → 일반 이동 → 다음 AI`

세 번의 잡기가 각각 추가 던지기를 줬다. 이 표본의 20회 결과 중 윷·모는 없었지만 잡기 10회 때문에 추가 던지기가 10회 발생했다. 따라서 윷·모가 보이지 않는데 같은 AI가 계속 던지는 것만으로 오류라고 볼 수는 없다.

## 재현과 한계

```sh
npm test
node scripts/audit-ai-turns.cjs 50
npm run dev
```

개발 서버의 `/scripts/ai-turn-audit.html`에서 가속 6판 또는 정상 속도 20회 버튼을 누른다. 이 페이지는 검증 전용으로 모든 좌석을 AI로 바꾸며, 일반 게임의 모드·규칙은 변경하지 않는다.

브라우저 결과 저장에는 `node scripts/measure-throw.cjs`의 로컬 4178 포트 수집 서버를 사용했다. 세 종류의 결과를 모으려면 `node scripts/report-ai-turn-audit.cjs`를 실행한다.

[원시 결과·정상 속도 시간순 로그·검사 대상 소스 해시](./ai-turn-audit.json)를 함께 보존했다.

고정된 시드 표본이며 모든 브라우저 이벤트 경합을 증명하는 검사는 아니다. 특히 정상 속도 표본은 완주 1판이 아닌 20회 던지기까지만 관찰했다. 다만 이번에 관찰된 긴 차례는 모두 추가 던지기 권한과 일치했다.
