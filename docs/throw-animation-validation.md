# 윷 던지기 연출 검증 — 2026-10-27

현재 연출은 결과 표시 때의 착지 끊김을 개선했다. 블러 ON 조건에서는 이전·현재의 평균 FPS가 사실상 같았으며, 블러 OFF 조건에서는 현재 연출이 더 높게 측정됐다. 조건별 6회 표본이므로 성능 우위를 일반화하지 않는다.

## 비교 대상과 방법

- 이전: `1931602` (윷 연출 변경 전)
- 현재: `f628c1e` (PR #1 병합 후)
- Windows Chrome, 실제 CSS viewport 1600×900. 브라우저 확대율을 고려해 viewport를 확인했다.
- 동일 난수 시드 400–405. 유효 던지기 5건, 강제 낙 1건.
- Web Animations API로 가락 애니메이션 시간을 정확히 1450ms에 고정하고, 결과 확정 전후 각 가락 본체 네 모서리의 화면 좌표를 비교했다.
- 이 검사는 시간 고정 상태의 기하·타이밍 검사이며, 실시간 재생 FPS나 사람의 미적 평가가 아니다.

## 전경 실시간 측정

Chrome 155, Windows, Core Ultra 7 155H에서 실제 창을 복원하고 해당 탭을 선택한 상태로 측정했다. WebGL이 보고한 렌더러는 **Intel Arc / ANGLE D3D11**이며, 설치된 RTX 4050으로 실행됐다고 가정하지 않았다. DPR은 0.75, 실제 CSS viewport는 1600×900이었다.

각 조건은 1.8초 대기 측정, 별도 워밍업 1회, 동일 시드 던지기 6회로 구성했다. 순서는 이전 ON → 현재 ON → 현재 OFF → 이전 OFF다. 대기 FPS는 1회 구간, 던지기 FPS는 6회 산술평균이다. P95는 각 던지기의 프레임 간격 P95를 다시 평균한 값이다.

| 연출 | 블러 | 대기 fps | 던지기 평균 fps | 던지기별 범위 | 평균 P95 간격 | 50ms 초과 간격 합계 |
|---|---|---:|---:|---:|---:|---:|
| 이전 | ON | 53.6 | 62.3 | 52.3–70.2 | 25.1ms | 2 |
| 현재 | ON | 51.2 | 62.3 | 57.6–66.7 | 25.1ms | 1 |
| 현재 | OFF | 73.6 | 76.3 | 60.3–95.6 | 23.7ms | 2 |
| 이전 | OFF | 92.4 | 63.4 | 56.2–75.3 | 30.5ms | 9 |

블러 ON에서는 애니메이션 교체만으로 평균 FPS가 향상됐다고 볼 수 없다. 현재 연출에서 블러를 끄면 이번 표본의 평균 던지기 FPS는 약 22.5% 높아졌다. 블러 OFF의 이전 대비 현재 차이는 약 20.3%지만, 대기 FPS도 실행 간 차이가 크므로 반복·교차 순서 측정 없이 확정적 성능 향상으로 주장하지 않는다.

초기 측정에서는 탭이 비활성 상태이거나 Chrome 창이 최소화돼 rAF가 약 1초 간격으로 제한됐다. 이 데이터는 제외했다. 마지막 조건에서도 대기 프레임 제한이 감지된 1회는 중단하고 다시 실행했다. 실패한 대기 검사는 유효 FPS 표본에 포함되지 않는다.

rAF 빈도는 프레임 스케줄링 지표이며 GPU가 실제 표시한 프레임 수를 보증하지 않는다. 모바일/저사양 기기, 프레임 트레이스, 사람의 미적 평가는 아직 미검증이다. 현재 블러 ON의 대기 51.2fps는 이슈 #2의 55fps 목표에도 미달하므로 해당 이슈를 해결됐다고 보지 않는다.

권고: 현재 연출은 유지할 만하다. 착지 전환 결함은 해소됐고, 동일 블러 조건에서 평균 FPS 저하는 관찰되지 않았다. 다음 최적화 대상으로는 패널 블러가 적절하지만, 질감 변경과 실기기 성능을 별도로 검증해야 한다.

원시 측정과 시드별 결과는 [측정 데이터](./throw-animation-measurements.json)에 보존했다.

## 재현

`http://127.0.0.1:4178/`에서 비교 버전을 선택한다. 실시간 검사는 해당 게임 탭을 실제로 선택하고 Chrome 창을 가리지 않은 상태로 유지한다. 결과는 Git에서 제외된 `preview-build/throw-*.json`에 저장된다. `착지 시점 정합성 검사`는 실시간 FPS와 별도로 실행할 수 있다.

검증 도구만 추가했으며, 게임 소스 변경·커밋·푸시는 하지 않았다.
