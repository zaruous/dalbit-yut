# 기본 사각형 윷판과 AI 관전

처음 접속하면 기본 사각형(S)이 표시된다. 팔각 순환형(A)과 이중 링형(B)은 상단과 게임 설정에서 계속 선택할 수 있다. 이전에 제외한 확장 교차형(C)을 복원한 것이 아니다.

## 판 구성

- 사각형 바깥길 20개, X자 지름길의 중간 자리 8개와 중앙 1개: 총 29개 자리.
- 오른쪽 아래 출발·완주 칸 `O0`에서 반시계 방향으로 이동한다. 첫 갈림길은 오른쪽 위 `O5`, 두 번째는 왼쪽 위 `O10`, 왼쪽 아래는 `O15`다.
- 갈림길에 정확히 멈춘 뒤 다음 이동에서 지름길을 선택한다. 중앙에 정확히 멈추면 귀환 방향으로 전환할 수 있으며, 한 번의 이동으로 중앙을 지나갈 때는 직진한다.
- 빽도는 실제 이동 경로를 거슬러 간다. 도 → 빽도는 기존 게임과 같이 `O0`으로, 추가 빽도는 `O19`, `O18` 방향으로 간다.
- 기존 게임의 완주 규칙을 유지했다. `O0`에 닿는 것은 도착 지점 정차이며, 그 뒤 전진으로 통과하면 `FIN`이다. 시작점에 닿는 즉시 완주하는 다른 지역 규칙으로 바꾸지는 않았다.

29개 자리 구성은 [한국민족문화대백과사전 윷놀이](https://encykorea.aks.ac.kr/Article/E0042794)를 참고했다. 이동 결과와 추가 던지기의 일반 설명은 [국립민속박물관 어린이박물관](https://www.nfm.go.kr/kids/elecontents/view.do?topic=46)을 참고했다. 세부 이동 규칙은 위에 명시한 기존 게임 규칙을 적용한다.

## AI 관전

상단 **AI 관전** 또는 게임 설정에서 AI 2~4명을 선택하면 모든 좌석이 자동으로 던지고 이동한다. 황금·청월·초록·홍단 AI의 현재 차례와 사용 결과, 잡기와 추가 던지기 이유를 볼 수 있다.

- `/?watch=1`: 기본판 AI 4인 자동 시작
- `/?watch=1&players=2`: 기본판 AI 2인
- `/?watch=1&players=3&board=B`: 이중 링 AI 3인
- `board=A`: 기존 팔각형, `board=S` 또는 생략: 기본판

일시정지는 진행 중인 던지기·이동을 마친 뒤 다음 행동부터 멈춘다. 재개는 같은 경기 상태에서 이어지고, **새 AI 대전**은 현재 인원·판으로 새 경기를 시작한다. 사람 참가자가 있는 모드에서는 수동 말 선택과 목적지 확인을 유지한다.

## 검증

- `test-standard.cjs`: 기본 선택, 외곽 20개·전체 29개, 사각 좌표, 지름길 선택·통과, 중앙 경유, 빽도 경로, 업은 말의 잡기·추가 던지기·완주.
- 기존 A/B 경로 회귀 검사와 세 맵 225판, 탐색 AI 경기 36판 종료 검사.
- Laya 연결 도구의 기본판 거리 계산과 입력 설명을 `O5/O10` 갈림길과 `O19` 외곽에 맞췄다. 이는 새 판의 모델 승률이나 파인튜닝을 검증했다는 뜻이 아니다. 과거 Laya 비교 데이터의 A/B 실험 조건도 바꾸지 않았다.
- 브라우저에서 기본 주소의 사각형 판 표시와 기존 맵 선택지를 확인했다. 관전 모드에서 일시정지 중 상태 유지와 재개 후 진행, 작은 모바일 폭의 가로 넘침 없음도 확인했다.
